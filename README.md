# PageWitness

**Consensus-backed, semantically verified webpage visual attestations.**

PageWitness is a decentralized web audit protocol running on GenLayer. It allows users to create immutable, timestamped attestations of what a public webpage displayed at a specific time. 

Unlike naive solutions that compare screenshots byte-for-byte (which fail due to rendering non-determinism) or require exact string matches on LLM responses (which fail under validator greyboxing), PageWitness uses semantic equivalence checks under GenLayer's Equivalence Principle to achieve robust, real-world consensus.
